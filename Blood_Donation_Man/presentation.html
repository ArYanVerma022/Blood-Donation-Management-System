Project Overview

Introduction & Project Background

Problem Statement

  • Finding blood donors during medical emergencies is often chaotic and time-consuming.
  • Paper records in small hospitals lead to missing donor histories and inaccurate inventory counts.
  • Absence of pre-screening causes unsafe donations or last-minute rejections at donation centers.

Core Objectives

  • Digitize donor registration with blood group, contact details, and location filters.
  • Automate preliminary pre-donation health screening for donor safety.
  • Track real-time stock levels across all 8 blood groups with low-stock warnings.
  • Automate patient blood request processing and administrative inventory sync.

Use Cases

Real-World Applications of JeevanRakt

1. Hospital Inventory Management

Allows local health clinics and small blood banks to track available units, maintain low-stock alerts, and fulfill emergency patient orders without expensive software.

2. Donor Matchmaking Directory

Connects patients needing immediate transfusions with nearby voluntary donors filtered by blood group, city location, and active status.

3. Preliminary Health Assessment

Saves staff time by collecting donor symptoms, medical history, procedures, and alcohol intake before blood bank laboratory testing.

4. Administrative Analytics & Reports

Provides database logging of donation histories, screening records, stock adjustments, and printable summary reports for academic evaluation.

Technical Architecture

Technology Stack Used

PHP 8.x (PDO Engine)

Backend & Security

Handles server-side execution, session authentication, input sanitization, screening rules engine, and SQL injection prevention via PDO prepared statements.

MySQL Database

7 Relational Tables

Stores admin credentials, user accounts, donor profiles, screening logs, donation transactions, blood stock units, and patient request records.

HTML5, CSS3 & Bootstrap 5

Frontend Styling

Clean student project visual style with light blue containers, dark blue navbar, blood red buttons, custom SVG graphics, and responsive components.

XAMPP Development Stack

Apache + MariaDB

Cross-platform local web server environment running Apache HTTP Server and MariaDB MySQL database for local deployment.

System Capabilities

Key Features & Screening Engine

Public & Donor Modules

  • Donor Registration: Validates age (18-65), blood group, contact details & duplicate checks.
  • Pre-Donation Screening: Evaluates symptoms, medical history, procedures & alcohol intake.
  • Automated Outcomes: Displays 🟢 Proceed, 🟡 Review Required, or 🔴 Temporarily Deferred.
  • Donor Directory: Search active donors by Blood Group, City, and Status.

Admin & Inventory Control

  • Admin Dashboard: Displays 4 main stat cards, recent donors, and low-stock alerts.
  • Donation Auto-Sync: Logs donations, auto-increments stock & updates last donation date.
  • Request Completion: Approves patient requests and auto-deducts blood stock units.
  • Printable Reports: Generates a summary matrix for official college presentation.
